# Makers' marks

`qwen.svg` and `minimax.svg` are the colour icons of Lobe Icons
(`@lobehub/icons-static-svg`, https://github.com/lobehub/lobe-icons), MIT licensed,
Copyright (c) 2023 LobeHub (the licence is in `LICENSE-lobe-icons.txt`), with the fixed
`width`, `height` and `style` attributes removed so the cockpit sizes them: `qwen.svg`
from 1.102.0 (`icons/qwen-color.svg`, Qwen's new mark, its three shapes in blue; the
cockpit showed the former purple star of 1.95.1 until v1.44.1), `minimax.svg` from 1.95.1. `alephalpha.svg` is the same set's Aleph Alpha icon (`icons/alephalpha.svg`, which
the set ships in one colour only), with the same three attributes removed. `nvidia.svg` is
the same set's colour NVIDIA icon (`icons/nvidia-color.svg`), the same three attributes
removed. `unsloth.svg` is the same set's colour Unsloth icon (`icons/unsloth-color.svg` of
1.102.0, sha256 068c4d17e21e2008a8660637177c061f6dddf36c1bac590d46617f01e48b0ef3 as published), the
same three attributes removed: the Qwen3.8 Flash-Next Unsloth GGUF lane serves Unsloth's GGUF
quantization of Qwen's model. `liquid.svg` is the same set's Liquid AI icon (`icons/liquid.svg` of
1.102.0, which the set ships in one colour only, sha256
4727b1cbd33bd256aca5be79a7d91a4f2753b2feb0dcfbb7b9fb3f23928c2467 as published), the same three
attributes removed. The marks themselves belong to their owners (Qwen to Alibaba Cloud, MiniMax to
MiniMax, Aleph Alpha to Aleph Alpha, NVIDIA to NVIDIA, Unsloth to Unsloth AI, Liquid AI to Liquid
AI); the cockpit shows them only to say which model a lane runs.

`thinkingmachines.svg` is no maker's mark: a plain badge of Thinking Machines' initials, drawn for the cockpit (an
outlined square and the letters TM, in the page's own colour), for the Inkling 2 Mini lane. Lobe Icons has no Thinking
Machines icon (1.106.0, its latest on 2026-11-24), and the model's repository at the lane's pinned revision ships no
logo. The name belongs to its owner, and the cockpit shows it only to say which model the lane runs.

`ornith.svg` is Ornith AI's round avatar, cropped from the logo its authors publish in their
model's repository (`assets/ornith_logo.png` of https://github.com/ornith-ai/Ornith-1 at commit
7ad11eb, MIT licensed, Copyright (c) 2026 deepreinforce.ai, the licence is in
`LICENSE-ornith.txt`) and scaled to 96 pixels, a PNG inside an SVG so that the cockpit sizes it as
it sizes the others. Lobe Icons has no Ornith icon (1.97.0, its latest on 2026-10-22). The mark
belongs to its owner, and the cockpit shows it only to say which model the Ornith 1.5 122B lane
runs.
